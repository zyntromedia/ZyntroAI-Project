🔒 Security Rules — NON-NEGOTIABLE
❌ NEVER commit .env — already in .gitignore
❌ NEVER hardcode secrets — use os.getenv() or settings
❌ NEVER f-string SQL queries — use ORM / parameterized queries
❌ NEVER allow CORS * in production — explicit origins only
❌ NEVER expose stack traces — generic messages to client
✅ Input validated — Pydantic on EVERY request
✅ Auth required — on ALL non-public routes
📋 Pull Request Requirements
 DRAFT until green — mark ready-for-review ONLY when all checks pass
 Plan approved — Issue plan reviewed BEFORE coding started
 Tests pass — including new code
 Coverage ≥80% — or maintained
 No lint/type errors
 Security scan clean — no critical findings
 Description complete — what, why, manual steps, screenshots
 One purpose per PR — keep changes focused
