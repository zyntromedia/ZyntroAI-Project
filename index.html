⚡ คำสั่งสำคัญที่ใช้บ่อย (API Cheatsheet)

ค้นหาและคัดลอกคำสั่ง Termux API สำหรับนำไปสร้างสคริปต์

คำสั่ง (Command) หน้าที่ (Description) ตัวอย่างการใช้งาน Action
termux-battery-status ดูสถานะแบตเตอรี่ เปอร์เซ็นต์ และอุณหภูมิ ตรวจสอบก่อนรันงานหนัก
termux-clipboard-get อ่านข้อความล่าสุดจากคลิปบอร์ด คัดลอกลิงก์ → วางลงในสคริปต์
termux-clipboard-set "ข้อความ" เขียนข้อความลงในคลิปบอร์ดมือถือ สร้างลิงก์แล้วคัดลอกทันที
termux-notification ส่งการแจ้งเตือน (Notification Bar) แจ้งเมื่อ git push เสร็จสมบูรณ์
termux-toast "ข้อความ" แสดงข้อความป๊อปอัปสั้นๆ บนหน้าจอ แจ้งผลการทำงานด่วน
termux-vibrate สั่งให้ระบบสั่นตามระยะเวลาที่กำหนด (-d ms) สั่นแจ้งเตือนเมื่อเกิด Error หรือเสร็จงาน
termux-share -a send "ไฟล์" ส่งไฟล์ออกไปยังแอปอื่นบนระบบ Android ส่งไฟล์ที่รันสร้างเสร็จไป LINE/Gmail
termux-open-url "URL" เปิดลิงก์ใน Chrome/Browser เริ่มต้น เปิด GitHub Pull Request หลัง Push

🚀 สคริปต์อัตโนมัติพร้อมใช้งาน (.sh Scripts)

เลือกดูคัดลอกหรือดาวน์โหลดสคริปต์การทำงานอัตโนมัติบนมือถือ

setup-mobile.sh

สคริปต์สำหรับการ Setup ZyntroAI / โปรเจกต์ Git บนมือถือครั้งแรก

#!/data/data/com.termux/files/usr/bin/bash
# setup-mobile.sh — ตั้งค่า ZyntroAI บนมือถือครั้งแรก
set -e

echo "🚀 เริ่มตั้งค่าโปรเจกต์บนมือถือ..."

# 1. ตรวจสอบเครื่องมือ
command -v git >/dev/null || { echo "❌ ติดตั้ง git ก่อน: pkg install git"; exit 1; }

# 2. ตั้งค่า Git (ครั้งแรก)
git config --global user.name "zyntromedia"
git config --global user.email "zyntro.ai.studio@gmail.com"
echo "✅ ตั้งค่า Git เรียบร้อย"

# 3. โคลนโปรเจกต์
cd ~/storage/shared  # หรือโฟลเดอร์ที่ต้องการ
if [ ! -d "new-crystalcastle" ]; then
    git clone https://github.com/ZyntroAI/new-crystalcastle.git
    echo "✅ โคลนสำเร็จ"
else
    echo "ℹ️ มีอยู่แล้ว — ดึงอัปเดต"
    cd new-crystalcastle && git pull
fi

# 4. แจ้งเตือนเมื่อเสร็จ
termux-notification --title "✅ ตั้งค่าเสร็จ" --content "พร้อมใช้งาน Obsidian แล้ว"
termux-vibrate -d 500

echo "🎉 เสร็จแล้ว! เปิด Obsidian → ชี้ไปที่ new-crystalcastle/docs/"
คำสั่งให้สิทธิ์และรัน: chmod +x setup-mobile.sh && ./setup-mobile.sh

sync-repo.sh

สคริปต์สำหรับดึงอัปเดตจาก GitHub พร้อมส่ง Notification และ Toast บนมือถือ

#!/data/data/com.termux/files/usr/bin/bash
# sync-repo.sh — ดึงอัปเดต + แจ้งผล
cd ~/storage/shared/new-crystalcastle

git pull origin main 2>&1 | tee /tmp/sync.log

if [ $? -eq 0 ]; then
    termux-notification --title "✅ ซิงค์สำเร็จ" --content "อัปเดตจาก main เรียบร้อย"
    termux-toast "✅ Sync OK"
else
    termux-notification --title "❌ ซิงค์ล้มเหลว" --content "ตรวจสอบอินเทอร์เน็ตหรือสิทธิ์"
    termux-vibrate -d 1000
fi
วิธีใช้งานประจำวัน: chmod +x sync-repo.sh && ./sync-repo.sh

setup-ssh.sh

สคริปต์อัตโนมัติสร้าง SSH Key และแสดง Public Key เพื่อคัดลอกลง GitHub

#!/data/data/com.termux/files/usr/bin/bash
# setup-ssh.sh — สร้าง SSH Key อัตโนมัติบน Termux
set -e

EMAIL="zyntro.ai.studio@gmail.com"

echo "🔑 กำลังสร้าง SSH Key แบบ ED25519..."

if [ ! -f ~/.ssh/id_ed25519 ]; then
    ssh-keygen -t ed25519 -C "$EMAIL" -f ~/.ssh/id_ed25519 -N ""
    echo "✅ สร้าง SSH Key เรียบร้อยแล้ว!"
else
    echo "ℹ️ มี SSH Key อยู่แล้ว"
fi

# คัดลอก Public Key ลง Termux Clipboard
PUBLIC_KEY=$(cat ~/.ssh/id_ed25519.pub)
echo "$PUBLIC_KEY" | termux-clipboard-set

termux-toast "📋 คัดลอก SSH Key ลง Clipboard แล้ว!"
termux-notification --title "🔑 SSH Key Ready" --content "เปิด GitHub → Add SSH Key แล้ววางได้เลย"

echo "------------------------------------------------ shadow"
echo "👇 นี่คือ Public Key ของคุณ (ถูกคัดลอกลง Clipboard แล้ว):"
echo ""
echo "$PUBLIC_KEY"
echo ""
echo "👉 นำไปวางใน: https://github.com/settings/ssh/new"

🔐 คู่มือตั้งค่า SSH Key (ไม่ต้องกรอกรหัสผ่านซ้ำ)

เพื่อความปลอดภัยและการ Push Code ขึ้น GitHub ได้ทันทีจากมือถือ

Step 1: สร้าง SSH Key ใน Termux

รันคำสั่งเพื่อสร้าง Ed25519 Key (ปลอดภัยสูงและประมวลผลเร็ว):

$ ssh-keygen -t ed25519 -C "zyntro.ai.studio@gmail.com"

# กด Enter ผ่านทุกขั้นตอนได้เลย

Step 2: อ่านและคัดลอก Public Key

ใช้ Termux API เพื่อส่ง Key เข้าคลิปบอร์ดมือถือทันที:

$ cat ~/.ssh/id_ed25519.pub | termux-clipboard-set

# Public Key จะถูกคัดลอกลงมือถือทันที

Step 3: เพิ่ม Key บน GitHub
  1. เปิดเบราว์เซอร์ไปที่ github.com/settings/ssh/new
  2. ช่อง Title: ตั้งชื่อเครื่อง เช่น Android-Termux
  3. ช่อง Key: กด วาง (Paste) ค่า Public Key ที่คัดลอกมา
  4. กดปุ่ม Add SSH key
Step 4: ทดสอบการเชื่อมต่อ

ทดสอบการเชื่อมต่อ SSH กับ GitHub จาก Termux:

$ ssh -T git@github.com

Hi zyntromedia! You've successfully authenticated.

1. Termux รัน ./sync-repo.sh ดึงข้อมูลล่าสุด
